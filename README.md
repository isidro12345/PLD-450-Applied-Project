Silent Hill Academic Documentation Project

Overview
This repository contains an academic front-end documentation project focused on the Silent Hill video game series. The project was developed as part of a university applied project and emphasizes content organization, visual layout, and structured presentation rather than back-end development.
The site presents narrative summaries, character profiles, and thematic analysis of Silent Hill 1–4, using static web technologies to demonstrate front-end design principles and documentation practices.
Project Objectives
Present complex narrative and symbolic material in a clear, structured format
Apply front-end web design fundamentals (HTML & CSS)
Demonstrate academic research synthesis through digital documentation
Practice layout consistency, navigation flow, and visual hierarchy
Translate written analysis into a user-friendly web experience
Scope & Features
Static, front-end–only implementation
Structured pages covering:
Game overviews
Character descriptions
Narrative summaries
Symbolism and thematic elements
Visual layouts designed for readability and accessibility
Supporting screenshots and academic documentation
Technologies Used
HTML5
CSS3
No JavaScript or back-end frameworks
Version control via GitHub
Academic Context
This project was completed as part of a university applied course and is intended to demonstrate:
Front-end design competency
Technical documentation skills
Ability to organize and present complex information
Academic research translation into digital form
All game-related content is used strictly for educational and non-commercial purposes.
